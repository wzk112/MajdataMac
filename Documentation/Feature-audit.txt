九路音量核对（原 Edit/SubWindow/SoundSetting.xaml.cs + View/SoundEffect.cs）
  BGM：音乐、节拍器、录制开场 track_start 与 clock_count；主音量另设。片尾未接入。
  Answer：短音符头、Hold 头尾的参考节奏音，同刻去重。
  Judge：普通头判定/普通 Hold 尾；区域模拟下 Miss 不发成功判定音。
  Slide：普通启动及 Break Slide 启动。
  Break：Break 判定和爆破声。
  BreakSlide：Break Slide 完成两层音效。
  EX：EX 判定；Break EX 保留 EX 的独立通道。
  Touch：Touch 判定音。
  Hanabi：烟花结束音、TouchHold 持续音；持续音使用实际 Hold 时长。
  九路均有 0–100%、静音、独奏、电平，另有主音量、重置、存默认值。
  所有声音经过同一个采样时钟/变速单元，增益立即应用；导出不按结果音量
  自动归一化，因此 50% 和静音不会被归一化抵消。
  有限的固定峰值余量用于避免九路同时最大音量削波。

0.3.3 输出和交互补充
  跟随系统默认媒体输出，监听 CoreAudio 与引擎配置通知，复用已生成音轨重连。
  重连保留位置/速度/混音，暂停或停止取消续播；硬件实际录屏采集链路仍需实测。
  独立全曲进度条，时间轴可见范围单独控制，类型图例和不同形状区分音符。

0.3.4 舞台和导出
  独立窗口舞台始终居中，横向空间足够时在等宽两侧显示完整信息。
  按原 UI/ObjectCounter.cs 核对五类音符计数、五档判定、FAST/LATE、FiNALE 和
  DELUXE 达成率、COMBO/SCORE/DX SCORE、模式与时间，附封面及谱面元数据。
  BREAK 单独计数；TouchHold 计入 HOLD。前缀快照支持回拖，不逐帧扫描全谱。
  实验模式按实际模拟结果统计，不将 GOOD/MISS 填成最高分；空谱避免零分母。
  烟花、击打光效、长押粒子开关共用于预览/导出，关闭时直接跳过对应绘制。
  视频支持 720/1080/1440/2160 方形及 720p/1080p/1440p/4K 16:9（60 fps）。
  宽屏元数据为可选项，导出读取启动时的谱面/难度快照；实时预览仍随窗口。

0.3.5 性能与显示
  隔离舞台高频时钟、App/Scene、统计、时间轴工具栏和播放按钮；中央文字缓存。
  全部统计、区域编号、特效和 120 Hz 选项保留，未降低显示数据或分辨率。
  判定区按压高亮独立开关，持久化并用于预览/视频导出；不改变判定结果。
  72 项测试通过。实机无采样器对照与剩余掉帧见 Rendering-status.txt。
  仍使用 Canvas / Metal 烟花着色器，没有独立的 Metal 批量精灵渲染器。

0.3.6–0.3.7 时钟与导出补充
  音频时钟按 host time 在采样块之间连续插值，固定刷新设置不再允许系统降至 30 Hz。
  导出改为连续 PV 解码、Metal / Core Image 背景转换、复用 SwiftUI 渲染图及编码
  缓冲池；所有特效、数据和像素尺寸保留。81 项测试通过，详细对照见 Rendering-status.txt。

0.3.8 稳定性补充
  时间轴播放时间和网格标签直接绘制预缓存字形，替换崩溃报告中的 NSString 动态
  字体属性路径；保留全部文本。60,000 帧原生重绘压力与 83 项回归通过。

0.3.9 录制与编码
  录制开场 5 秒：原信息卡素材、字体、难度颜色与三段动画；track_start 使用 BGM
  音量，clock_count 从音乐零秒起按初始 BPM 调度。原有负时间预滚另行保留。
  普通播放和单独 WAV 导出不增加开场；原版实时 OP 按钮未移植。AP 结尾已在
  1.0.0 build 16 加入，实验模拟仅在全部结果至少为 Perfect 时显示 AP。
  默认 HEVC 硬件编码，可选 H.264；输出帧传输使用 Metal / Core Image，有 CPU 回退。

Classic 自动播放的宽屏右栏按用户要求隐藏五档判定数量与 FAST/LATE，保留达成率、
COMBO、分数和播放时间；区域模拟模式继续显示判定明细。该布局共用于舞台与导出。

0.3.10 输出设备兼容性
  AVAudioEngine 输出单元显式设置 CurrentDevice，启动后读回确认；支持默认输出或
  以 UID 选择设备。虚拟设备消失时暂用系统默认，重新出现时恢复；界面显示实际输出。
  监听设备列表/默认输出/音频服务，并定期检查引擎绑定，支持设备初始化延迟重试。
  用户要求自行测试：本版不宣称已确认 iShot 捕获成功，没有自动录音或播放验证。
