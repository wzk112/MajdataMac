# 可视化编辑回归与界面检查

检查日期：2026-10-16。环境：Apple silicon、macOS 27.0.1、Swift 6。

## 编辑正确性

- 删除 ``(120){4}1`3`5,7,E`` 的任一音符，剩余音符仍保留各自时间与结束时间；回归包含同组多音符、空白、中文注释、Unicode 与偏移。随机插入/删除也检查保留下来的音符时刻。
- `135` 等简写音符可分别添加 B/X；修改会插入必要的 `/`，只选中被修改的音符，保持其他音符时刻和修饰不变。
- 菜单与侧栏镜像、旋转、分音通过同一模型入口记录历史；撤销和重做逐步恢复原文本及选区。
- 有序鼠标轨迹按弧长重新采样。544 条合法起终点/形状组合返回相同的底层路径键，兼容等价的形状写法；另有真实 AppKit 鼠标事件驱动整圈、p/q 回环的舞台输入测试。
- 缺少轨迹、静止点、非有限坐标不参与有序轨迹匹配。WiFi 仍使用显式工具选项。

## 统一界面与过渡

主窗口、侧栏、工具区、检查器、时间轴、播放控制、设置和混音器采用系统原生透明 Liquid Glass（clear）。浅色使用珍珠雾灰、深色使用石墨灰的静态背景，标题栏透出同一背景，不铺蓝色渐变；设置、检查器去掉实色表单分组。舞台内容保持自己的渲染与配色，玻璃用于编辑界面。没有持续背景动画或自定义折射着色器。

模式切换控件保留图标与文字，选中背景使用弹簧过渡。内容切换使用轻微缩放及淡入淡出；播放控制保留在共用容器。工作台、检查与分析、使用指南及侧栏和检查器展开使用同一弹簧参数。工具栏与页面图标使用原始彩色符号和固定强调色，可用控件维持活跃强调外观，禁用态仍单独区分。系统“减少动态效果”启用时关闭这些自定义动画，“减少透明度”启用时玻璃面板使用实色背景。

布局检查覆盖 600、850、1100、1440 点宽的可视化工作区，确认竖谱与舞台不越界，舞台保持正方形。600 点对应主窗口两侧面板展开后的内部工作区，不代表应用最小窗口宽度改为 600 点。

前一轮实际窗口检查包含浅色、深色、两种编辑模式、侧栏、检查器及紧凑工具选项（时长、修饰、撤销、变换）。最终珍珠灰/clear 版已实际复查浅色工作台、分析页、标题栏和失焦图标颜色。最终深色、指南与设置页的再次手动复查遇到界面连接中断，尚未完成；不把前一轮截图当成最终版验证。

## 流畅性检查的范围

竖谱按谱面修订重建音符区间索引，绘制、鼠标命中和长押端点查询使用可见时间范围；查询保留源码顺序、闭区间端点和跨视口长音符。回归以乱序输入及非顺序跳转对照原线性筛选。30,000 音符、500 次 8 秒范围查询的本机 release 微基准为线性 73.88 ms、索引 5.45 ms；这只衡量查询部分，不是整窗帧率。玻璃使用系统容器批处理，去掉额外描边/阴影，不增加背景计时器。

静音引擎测试在播放中反复切换编辑模式，核对源码、选区、准备音频 URL 和播放状态不变，并等待过渡后旧的 AppKit 画布移除。此检查验证状态与视图生命周期，不是 GPU 帧率或输入延迟测量；没有据此保证所有设备的刷新率。
