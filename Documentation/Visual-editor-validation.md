# 可视化编辑回归与界面检查

检查日期：2026-10-16。环境：Apple silicon、macOS 27.0.1、Swift 6。

## 编辑正确性

- 删除 ``(120){4}1`3`5,7,E`` 的任一音符，剩余音符仍保留各自时间与结束时间；回归包含同组多音符、空白、中文注释、Unicode 与偏移。随机插入/删除也检查保留下来的音符时刻。
- `135` 等简写音符可分别添加 B/X；修改会插入必要的 `/`，只选中被修改的音符，保持其他音符时刻和修饰不变。
- 源码输入、菜单与侧栏镜像、旋转、分音、批量替换通过同一模型历史撤销；真实 NSTextView 输入回归覆盖“输入→镜像→再输入→连续撤销/重做”和重建源码视图后继续撤销。相邻单字输入合并，移动光标或粘贴多字符会分开记录；组合输入只在提交后记录；播放刷新期间保留正在输入的拼音，不用模型文本覆盖未提交的组合串。
- 源码字体仍为等宽，行间距为字号的 20%，段落间距为 45%；回归用 NSLayoutManager 的实际行片段位置验证手动回车比软折行留白更大。
- 有序鼠标轨迹按弧长重新采样。544 条合法起终点/形状组合返回相同的底层路径键，兼容等价的形状写法；另有真实 AppKit 鼠标事件驱动整圈、p/q 回环的舞台输入测试。
- 缺少轨迹、静止点、非有限坐标不参与有序轨迹匹配。WiFi 仍使用显式工具选项。

## 统一界面与过渡

主窗口、侧栏、工具区、检查器、时间轴、播放控制、设置和混音器采用系统原生透明 Liquid Glass（clear）。浅色使用珍珠雾灰、深色使用石墨灰的静态背景，标题栏透出同一背景，不铺蓝色渐变；设置、检查器去掉实色表单分组。舞台内容保持自己的渲染与配色，玻璃用于编辑界面。没有持续背景动画或自定义折射着色器。

模式切换控件保留图标与文字。选中指示器使用 220 ms、页面与面板使用 300 ms 的三次贝塞尔缓动 `(0.22, 1, 0.36, 1)`，不超出起止值、不回弹；页面仅淡入淡出，去掉缩放。工具栏在完整与紧凑模式间连续改变宽度，播放按钮准备音频时保持图标尺寸。系统“减少动态效果”启用时关闭自定义动画，“减少透明度”启用时玻璃面板使用实色背景。侧栏页面采用显式按钮与统一的选中底色，快捷键切换编辑模式会返回工作台。

布局检查覆盖 600、850、1100、1440 点宽的可视化工作区，确认竖谱与舞台不越界，舞台保持正方形。600 点对应主窗口两侧面板展开后的内部工作区，不代表应用最小窗口宽度改为 600 点。

本轮在独立测试 App 中实际检查了左右面板分别展开/收起及两侧都关闭、浅色工作台与源码、深色工作台、深浅色设置页、窗口缩放和菜单镜像后的键盘 ⌘Z。收起后的工具区和舞台不再显示隐藏面板的文字或控件。源码撤销恢复了原文本和选区。追加的侧栏按钮已实际进入分析页，最终原生容器的侧栏和检查器控件也已在无障碍树中确认。指南、混音器、独立舞台的最后一轮人工复查因界面工具服务再次中断未完成；不把自动测试或较早截图当成这些页面的最终实测。

两侧的玻璃各自放在独立 NSHostingView 内，由 NSView 的 `clipsToBounds` 与图层 `masksToBounds` 同时约束。回归每 55 ms 反向切换，检查原画布与滚动视图保留、最终宽度恢复、绘制区域不越界，以及展开时的命中目标、可访问子视图和收起后的原生隐藏标记。采样验证位置单调且不超出两端；主线程繁忙时可能跳过中间帧，此测试不代表动画帧率。

## 流畅性检查的范围

竖谱按谱面修订重建音符区间索引，绘制、鼠标命中和长押端点查询使用可见时间范围；查询保留源码顺序、闭区间端点和跨视口长音符。回归以乱序输入及非顺序跳转对照原线性筛选。30,000 音符、500 次 8 秒范围查询的本机 release 微基准为线性 73.88 ms、索引 5.45 ms；这只衡量查询部分，不是整窗帧率。玻璃使用系统容器批处理，去掉额外描边/阴影，不增加背景计时器。

静音引擎测试在播放中反复切换编辑模式，核对源码、选区、准备音频 URL 和播放状态不变，并等待过渡后旧的 AppKit 画布移除。此检查验证状态与视图生命周期，不是 GPU 帧率或输入延迟测量；没有据此保证所有设备的刷新率。

预览音频根据排序后的音效事件、起止时间、音乐 URL、节拍器及实验区域模式输入判定能否复用。Classic 的镜像、换行和标题修改回归确认：原音频 URL 和播放位置保留，立即播放不进入准备态。实际改变音效的编辑仍重新生成混音；后台已在生成相同内容时点击播放，只更新播放意图。另有编辑发生在旧混音完成前的回归，确保旧音频不会作为新谱面结果发布。没有将所有音符编辑宣称为零等待。
